# AI News Intelligence Platform

An AI-powered news intelligence platform designed to collect, analyze, summarize, and compare news from multiple sources using Generative AI, RAG, and multi-agent architectures.

## Project Goals

- Build automated news ingestion pipelines.
- Extract and structure information from news articles.
- Generate AI-powered news summaries.
- Compare news coverage across multiple sources.
- Implement Retrieval-Augmented Generation (RAG).
- Build AI agents for research and analysis.
- Orchestrate multi-agent workflows using LangGraph.
- Expose capabilities through APIs and a user interface.
- Deploy the platform using Docker and AWS.

## Technology Stack

- Python
- Generative AI and LLMs
- LangChain and LangGraph
- Vector Databases
- FastAPI
- PostgreSQL
- Docker
- AWS
